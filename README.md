## 🧠 About Me

I build web platforms where AI does the actual work rather than sitting on top as a feature, and I build them end to end: API design, database work, the interface, and the deployment pipeline around it.

The problems I like are the ones where the hard part is not the model but everything around it — making it fast enough to feel interactive, structured enough to trust, and simple enough that someone who is not an engineer can use it.

## 🛠️ Featured Work

### [ArchionLabs](https://oshadha.com/work/archionlabs) · Hult Prize IIT Finalist
An AI platform that turns a text prompt into a 3D building, simulates pedestrian movement through it, and checks it against Sri Lankan building regulation. I built the generation pipeline and the MARL behaviour engine.
`Next.js` `FastAPI` `Three.js` `Claude API`
→ [Read the case study](https://oshadha.com/work/archionlabs) · [Live prototype](https://www.archionlabs.com/)

### [Dwellio](https://github.com/OshadhaVimuB/dwellio)
A real estate SPA built around a multi-parameter search engine: filters across location, price, bedrooms and listing date, a drag-and-drop favourites system, and shareable URL-encoded search state.
`React` `Vite` `React Router` `Jest`

### Traffic Data Analysis
A Python engine computing 15+ traffic metrics across vehicle classes and junctions, with peak-hour detection and a Tkinter histogram UI for comparing hourly volume between junctions.
`Python` `OOP` `Tkinter`
